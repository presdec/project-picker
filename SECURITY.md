# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory for this repository when available, or by contacting the repository owner directly.

Include:

- Affected version or commit
- Steps to reproduce
- Impact
- Any relevant config or environment details

Please do not open public issues for vulnerabilities until a fix or mitigation is available.
